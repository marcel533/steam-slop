AI content check

Is this game AI slop?

How much of a Steam game is AI-generated? Enter a title, get a slop score. A web app that estimates a 0 to 100% score from public store data, with a category breakdown, the evidence behind it and a link to the store page.

Features

Slop score0 to 100%, classified as AI Slop, Mixed or Legitimate.

How the score works

Entries come from two sources: curated entries on the homepage, scored from public information such as AI use disclosed by the developer, and every other Steam game, estimated automatically from store data. The overall score is the weighted average of the measurable categories.

CategoryWeightNotes
Store and capsule graphics40%Images are not analysed. Reads n/a unless the developer disclosed AI use.
Store text and patch notes30%Looks for LLM-typical phrasing and mentions of AI-generated content.
Asset flips30%Indicators of reused or repackaged assets.

Example: R.E.P.O.

  • Store art: n/a (images are not analysed)
  • Descriptions and patch notes: 40%
  • Asset flip signals: 25%
  • Two signals raised: no developer website listed, and developer news or patch notes mention AI-generated content
  • Calculation: (30 × 40 + 30 × 25) / 60 = 32.5, shown as 33%
  • Result: 33%, Legitimate
  • The review data source was unreachable, so the page warns that the score may be incomplete

Estimation signals

For non-curated games the estimate uses:

  • LLM-typical phrasing in the store description
  • developer news or patch notes mentioning AI-generated content
  • no developer website or support contact
  • very few user reviews
  • an unusually low price
  • Steam’s own “AI Generated Content Disclosure”, where present (best effort)

Limitations

The score is an indicator, not proof. It can be wrong in either direction. Do not use it to accuse a studio or developer.

If a data source (for example reviews) is unreachable, the score may be incomplete and the page says so.

Community data exists only for curated entries. Real community reporting would need its own database.

Run it

Needs Node.js 22.12 or newer (22 or 24 LTS recommended, Node 20 is end-of-life) and an internet connection. Optional settings are in the README and .env.example.

1. Install Node.js

With nvm (any distro, no root). The script is downloaded first and then run, so you can read it before executing:

curl -fsSL -o /tmp/nvm-install.sh https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh
bash /tmp/nvm-install.sh
source ~/.bashrc
nvm install 22
nvm use 22

Or with your package manager (version may be older, check with node -v):

sudo apt install nodejs npm        # Debian, Ubuntu
sudo dnf install nodejs npm        # Fedora
sudo pacman -S nodejs npm          # Arch

2. Unpack and start

unzip steam-slop.zip
cd steam-slop
npm install
npm run dev

Open http://localhost:3000

3. Stop

Press Ctrl+C in the terminal. If it still runs in the background:

fuser -k 3000/tcp
